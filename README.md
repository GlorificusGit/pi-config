# pi-config

Personal Pi extensions.

## Install

```bash
pi install git:github.com/GlorificusGit/pi-config
```

## Update

```bash
pi update --extensions
```

## Local testing

```bash
./scripts/setup-test
PI_CODING_AGENT_DIR=~/.pi/test pi
```

Creates an isolated profile at `~/.pi/test` to test local changes
